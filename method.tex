\section{Method}
\label{sec:method}

SurgAlign is a training-time refinement for weak surgical VLP. It leaves the dual-encoder backbone and the test-time pipeline unchanged, and only changes how a positive video-text pair is formed during pretraining. The key observation is simple: a weak interval can be semantically correct even when only a few of its frames visually support the paired text. SurgAlign therefore does not treat all frames in the weak interval as equally positive. Instead, it expands the interval into a local candidate window and builds a text-guided evidence view inside that window.

\subsection{Preliminaries}
\label{sec:method_setup}

Each training sample is written as
\begin{equation}
(V, [t_s, t_e], y),
\end{equation}
where $V$ is a surgical video, $[t_s, t_e]$ is the weak temporal interval, and $y$ is the paired text. In a standard CLIP-style baseline, $M$ frames are sampled from $[t_s, t_e]$, encoded by a visual backbone $E_v$, aggregated into one clip representation, and aligned with a text representation produced by a text encoder $E_t$. If $A_v(\cdot)$ is the temporal aggregation head and $P_v(\cdot), P_t(\cdot)$ are the projection heads, the baseline computes
\begin{equation}
\begin{aligned}
v_{\mathrm{glob}} &= \operatorname{norm}\!\left(P_v(A_v(E_v(c)))\right),\\
u &= E_t(y),\\
t &= \operatorname{norm}\!\left(P_t(u)\right),
\end{aligned}
\end{equation}
and optimizes a symmetric contrastive loss.

This formulation is effective when the sampled clip is already well aligned with the text. Our setting is weaker: the pair can be semantically valid even when the truly supportive visual evidence occupies only a subset of frames. In other words, the baseline uses one positive label for frames that do not equally support the paired text. SurgAlign keeps the same encoders and contrastive objective, but changes how the positive visual evidence is collected and aggregated during training.

\subsection{Overview}
\label{sec:method_overview}

SurgAlign has two training branches. Starting from a weak interval, we first sample candidate frames from an expanded local window. The global branch applies the usual temporal aggregation head to this candidate clip. The weighted branch instead uses the text to assign soft weights to the candidate frames and forms a second clip representation that emphasizes the most relevant frames. Training combines:
\begin{enumerate}
    \item a global branch that preserves stable interval-level video-text alignment; and
    \item a weighted branch that emphasizes text-relevant frames inside the expanded local window.
\end{enumerate}
All extra components are training-time only.

Figure~\ref{fig:method_overview} summarizes the pipeline. Query-conditioned frame weighting appears only in the auxiliary weighted branch during training, while inference remains unchanged from a standard CLIP-style model.

\subsection{Local Window Expansion}
\label{sec:method_expand}

Weak narration timestamps often miss the most informative visual moment by a small temporal offset. We therefore replace the original interval with a bounded expanded interval
\begin{equation}
[t_s', t_e'] = \operatorname{Expand}([t_s, t_e]; \rho),
\end{equation}
where $\rho \geq 1$ is an expansion ratio and the interval is clipped to the valid video duration. We then sample a multi-frame candidate clip
\begin{equation}
c_{\mathrm{exp}} = \{x_1', \ldots, x_M'\}
\end{equation}
from $[t_s', t_e']$.

This expansion is deliberately local. SurgAlign does not attempt full temporal grounding. It only enlarges the search space enough to keep nearby supportive frames available during training when the annotated interval is slightly misaligned.

\subsection{Text-Guided Frame Weighting}
\label{sec:method_selection}

Let the visual encoder produce frame tokens
\begin{equation}
\{h_1, \ldots, h_M\} = E_v(c_{\mathrm{exp}}),
\end{equation}
and let the text encoder produce token-level hidden states together with the pooled text feature
\begin{equation}
\{w_1, \ldots, w_L\}, \quad u = E_t(y).
\end{equation}
The projected global text embedding $t = \operatorname{norm}(P_t(u))$ is still used by the contrastive objective. The weighted branch instead uses token-level text states to score frames inside the expanded local window.

We first build a text query by mean-pooling the valid token states and applying a lightweight projection:
\begin{equation}
\bar{w} = \frac{1}{L'}\sum_{r=1}^{L} m_r w_r, \qquad
q = \operatorname{norm}(Q_t(\bar{w})),
\end{equation}
where $m_r \in \{0,1\}$ is the token mask and $L' = \sum_r m_r$. Each frame token is projected in the same latent space,
\begin{equation}
\tilde{h}_j = \operatorname{norm}(Q_v(h_j)),
\end{equation}
and matched with the text query through cosine similarity:
\begin{equation}
s_j = q^\top \tilde{h}_j.
\end{equation}

The frame weights are then computed as
\begin{equation}
\alpha_j = \operatorname{softmax}_{j}\left(\frac{s_j}{\tau_{\mathrm{evi}}}\right),
\end{equation}
where $\tau_{\mathrm{evi}}$ controls the sharpness of evidence selection. The weighted clip representation is obtained by weighted aggregation,
\begin{equation}
z_{\mathrm{evi}} = \sum_{j=1}^{M} \alpha_j h_j, \qquad
v_{\mathrm{evi}} = \operatorname{norm}(P_v(z_{\mathrm{evi}})).
\end{equation}

The weighted branch can be viewed as a denoised auxiliary view of the same weak pair. The global branch still provides stable clip-level supervision, while the weighted branch teaches the model to focus on the frames that best support the text.

\subsection{Training Objective and Inference}
\label{sec:method_objective}

Both training branches read the same candidate clip $c_{\mathrm{exp}}$. This keeps the frame pool fixed and isolates the difference to the aggregation rule: the global branch applies the standard temporal head, whereas the weighted branch applies text-guided frame weighting. The global branch therefore produces
\begin{equation}
v_{\mathrm{glob}} = \operatorname{norm}(P_v(A_v(E_v(c_{\mathrm{exp}})))).
\end{equation}
Both training branches share the same global text embedding $t$ and differ only in how the expanded clip is aggregated on the video side. Using $t$, we optimize two symmetric CLIP-style contrastive objectives:
\begin{equation}
\mathcal{L}_{\mathrm{glob}} =
\mathcal{L}_{v \rightarrow t}(v_{\mathrm{glob}}, t) +
\mathcal{L}_{t \rightarrow v}(t, v_{\mathrm{glob}}),
\end{equation}
\begin{equation}
\mathcal{L}_{\mathrm{evi}} =
\mathcal{L}_{v \rightarrow t}(v_{\mathrm{evi}}, t) +
\mathcal{L}_{t \rightarrow v}(t, v_{\mathrm{evi}}).
\end{equation}
The final objective is
\begin{equation}
\mathcal{L} =
\mathcal{L}_{\mathrm{glob}}
 + \lambda_{\mathrm{evi}} \mathcal{L}_{\mathrm{evi}}.
\end{equation}

Here, $\mathcal{L}_{\mathrm{glob}}$ preserves stable clip-level alignment, while $\mathcal{L}_{\mathrm{evi}}$ teaches the model to focus on text-relevant frames inside the expanded candidate window.

At inference time, SurgAlign falls back to standard CLIP-style encoding:
\begin{equation}
v = \operatorname{encode\_image}(c), \qquad
t = \operatorname{encode\_text}(y),
\end{equation}
followed by cosine similarity in the shared embedding space. No local window expansion or frame weighting is required at test time. SurgAlign is therefore a method for improving weak supervision during pretraining, not a query-conditioned inference system.
