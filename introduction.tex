\section{Introduction}

Surgical video-language pretraining (VLP) offers a scalable path to surgical video understanding because it can learn from weak video-text pairs instead of dense manual labels~\cite{lecturevideo2023,peskavlp2024,surglavi2025}. The supervision, however, is temporally imprecise. In surgical data, paired text usually comes from narrations, transcripts, or coarse temporal descriptions rather than precisely trimmed clips. A pair can therefore be semantically correct while the frames that visually justify the text occupy only a short subsegment of the interval, or appear slightly before or after it. Standard CLIP-style training ignores this structure and pools the sampled interval as a uniformly positive clip.

This mismatch matters most for fine-grained surgical transfer. Coarse workflow recognition can benefit from broad context, but step, action, tool, and triplet understanding depend much more on localized visual evidence. When all frames inside a weak interval contribute equally, supportive evidence is mixed with irrelevant context and temporally shifted content. The bottleneck is therefore not only noisy annotation; it is also the training rule used to consume weak temporal supervision.

We study this problem as \emph{temporal misalignment within weak video-text pairs}. Our goal is not full temporal grounding, a new retrieval head, or a query-conditioned test-time pipeline. Instead, we ask a narrower question: can surgical VLP improve if a weak interval is treated as an approximate temporal anchor and the model learns a better local visual view around it during training? This perspective is related to multiple-instance learning and weak temporal localization~\cite{dietterich1997mil,ilse2018attentionmil,li2023boostingwtal,hu2024mmplateau,li2024fps}, and it is also consistent with recent video-language work showing that text-guided aggregation can isolate more informative evidence than fixed temporal pooling~\cite{gorti2022xpool,li2023prost,liu2023stan}.

Based on this view, we propose \textbf{SurgAlign}, a simple misalignment-aware training framework for surgical VLP. SurgAlign treats each weak interval as a noisy temporal anchor, expands it into a bounded temporal neighborhood, samples candidate frames from that neighborhood, and uses the paired text to compute soft frame weights for a selected local visual view. The selected view is optimized together with a standard global branch, so the model preserves stable interval-level alignment while learning to emphasize locally supportive evidence. Hierarchical caption levels are used only as evidence-granularity priors: fine captions induce sharper selection, coarse captions allow broader weighting, and adjacent levels from the same video can optionally be regularized for local compatibility.

SurgAlign is intentionally lightweight. It introduces no new backbone, no new retrieval head, and no query-conditioned inference module. All extra logic is used only during pretraining, and inference remains standard CLIP-style independent video and text encoding. The contribution is therefore not a new test-time system, but a better way to consume weak temporal supervision during training.

We evaluate SurgAlign in a matched surgical-domain setting and ask whether misalignment-aware training improves zero-shot surgical understanding under a strong in-domain backbone. The clearest gains appear on tasks that depend on localized visual evidence, supporting the view that weak interval pairs should be treated as noisy anchors rather than uniformly reliable positives.

\noindent\textbf{Contributions.}
\begin{enumerate}[leftmargin=1.5em]
    \item We identify temporal misalignment inside weak surgical video-text pairs as an important source of supervision noise for surgical VLP.
    \item We propose SurgAlign, a training-time framework that combines bounded temporal expansion, text-guided local evidence selection, and hierarchy-aware selection priors while keeping standard CLIP-style inference unchanged.
    \item We show in matched surgical-domain evaluation that SurgAlign improves zero-shot surgical understanding, with the clearest gains on tasks that require localized visual evidence.
\end{enumerate}
