\section{Experiments}
\label{sec:experiments}

\subsection{Experimental Setup}
\label{sec:exp_data}

We evaluate SurgAlign with a fixed-epoch protocol designed to isolate the effect of weak-positive construction. The primary comparison is an \emph{internal matched baseline}: the same weak pretraining corpus, visual and text encoder families, temporal head, projection heads, frame budget, optimizer, epoch budget, and zero-shot evaluation scripts are used for both the baseline and SurgAlign. The baseline samples frames from the original weak interval and trains with the standard global CLIP-style objective. SurgAlign changes only the training rule for the weak positive pair by expanding the local window and adding the text-guided evidence branch described in Section~\ref{sec:method}.

The official checkpoint is fixed at epoch 50 for every method variant. We do not select checkpoints using downstream test performance. Each main condition is run with three random seeds and reported as mean $\pm$ standard deviation. Following the SurgCLIP/SurgLaVi evaluation convention~\cite{surglavi2025}, for phase, step, and action tasks we report Acc/F1 and treat F1 as the primary metric; for tool and triplet tasks we report mAP as the primary metric.

To test whether SurgAlign depends on surgical-domain initialization, we run a $2\times2$ initialization-control experiment. The surgical-initialization setting uses ConvNeXt-Large initialized from LemonFM and SurgicBERTa as the text encoder. The generic-initialization setting keeps the same model structure but removes surgical pretraining priors by using ConvNeXt-Large ImageNet initialization and \texttt{bert-base-uncased}. All other training and evaluation details are held fixed. SurgCLIP-$\beta$ and full SurgCLIP are included only as reported strong references, not as internal matched baselines.

\subsection{Success Criteria}
\label{sec:exp_success}

The paper is judged primarily by the matched internal comparison rather than by a claim of uniform dominance over reported external systems. SurgAlign is considered successful only if it provides stable gains over the internal baseline while keeping regressions bounded. The SurgCLIP-$\beta$ comparison is used to establish external competitiveness on evidence-sensitive tasks, not to claim that SurgAlign is a stronger overall system than every surgical VLP baseline. This distinction is important because published surgical VLP tables can differ slightly due to prompt templates, preprocessing, available data, dataset splits, checkpoint policy, or evaluation-script details even when they report the same task names and metrics.

\subsection{Main Zero-Shot Comparison}
\label{sec:exp_main}

The main result table will report the three-seed mean and standard deviation for the four internal conditions in Table~\ref{tab:main_2x2_design}. The same table will include reported CLIP, MedSigLIP, SurgVLP, HecVL, PeskaVLP, SurgCLIP-$\beta$, and full SurgCLIP values as external references under the SurgCLIP-style task and metric convention. These reference values are not used to define the internal causal claim because they may differ in data curation, initialization, prompt construction, preprocessing, evaluation scripts, training recipe, or checkpoint policy.

The downstream tasks cover broad workflow recognition and evidence-sensitive recognition: Cholec80, AutoLaparo, StrasBypass70, HeiChole, BernBypass70, and GraSP phase recognition; GraSP step recognition; SARRARP50 action recognition; CholeT50 triplet recognition; and Cholec80, HeiChole, and GraSP tool recognition. We separately analyze these groups because SurgAlign targets local evidence dilution, so the expected gains should be strongest on tasks whose labels are tied to short tool-tissue interactions rather than long-horizon procedure context.

The result registry for every row must record the run identifier, seed, initialization type, method variant, epoch, configuration hash, task, metric, value, and evaluation-script version. Numbers are added to the manuscript only after they can be traced back to this registry.

\subsection{Ablation Study}
\label{sec:exp_ablation}

The ablation study is designed around reviewer questions rather than around implementation convenience. All ablations use the surgical-initialization setting, fixed epoch 50, the same downstream scripts, and the same reporting convention as the main comparison. The closed ablation isolates two necessary ingredients: expanding the weak interval into a local search window, and reselecting evidence frames with the paired text. \emph{Expand-only} tests whether a larger candidate pool is sufficient by itself, \emph{Reselect-only} tests whether text-guided reweighting helps without temporal expansion, and \emph{Expand+Reselect} combines the two.

Table~\ref{tab:ablation_results} shows that Expand+Reselect improves the primary metric over the baseline on 9 of 12 tasks. For all eight Acc/F1 tasks, Expand+Reselect improves F1 over the baseline, with large gains on Cholec80 Phase, HeiChole Phase, AutoLaparo Phase, and SARRARP50 Action. The comparison against the single-factor variants shows why the components need to be combined: Expand+Reselect outperforms both Expand-only and Reselect-only on six of the eight Acc/F1 tasks, and the largest interaction effects appear on Cholec80 Phase, HeiChole Phase, GraSP Step, and SARRARP50 Action. These are the settings where merely expanding the window or merely reselecting frames can be unstable, but their combination provides a cleaner positive signal.

The mAP tasks are more mixed. Expand+Reselect improves Cholec80 Tool over the baseline, but it does not improve CholeT50 Triplet, HeiChole Tool, or GraSP Tool. This pattern defines an important boundary of the current method: the training-time evidence refinement is most reliable for phase, step, and action recognition, while tool/triplet retrieval may require stronger negative discrimination or a different downstream calibration strategy.

\subsection{Expanded-Window Evidence Analysis}
\label{sec:exp_evidence}

The mechanism analysis tests whether the expanded local window is actually used rather than serving as a formal augmentation. After training, we partition sampled frames into those inside the original weak interval and those in the expanded-only region, then aggregate five statistics:
\begin{itemize}
    \item OutFrac: the fraction of sampled frames outside the original weak interval but inside the expanded window;
    \item OutWeight: the total evidence weight assigned to those outside frames;
    \item Enrich: $\mathrm{OutWeight}/\mathrm{OutFrac}$, where values above $1$ indicate higher-than-uniform use of expanded-window frames;
    \item Top1-Out: the rate at which the highest-weight frame lies outside the original weak interval; and
    \item Entropy: the concentration of the learned frame-weight distribution.
\end{itemize}
This analysis is not interpreted as temporal localization accuracy because the weak timestamps do not provide frame-level ground truth. It is a functional check that SurgAlign uses the expanded candidate window and assigns non-uniform evidence weights rather than simply adding frames uniformly.

\subsection{Qualitative Visualization}
\label{sec:exp_qualitative}

We visualize six representative cases: two successful cases, two failure cases, and two cases in which the highest-weight frame lies outside the original weak interval. Each visualization should include the original weak interval, the expanded local window, sampled frames, frame weights, paired caption, and downstream prediction. The qualitative section is used to explain mechanism and limitations, not to replace the quantitative ablation.

\subsection{Reporting Rules}
\label{sec:exp_reporting}

The manuscript reports only fixed-epoch, three-seed aggregates for the official main comparison. If the internal baseline criteria in Table~\ref{tab:success_criteria} are met but the SurgCLIP-$\beta$ reference criteria are not, the paper remains a valid mechanism paper but the title, abstract, and conclusion should emphasize matched weak-positive construction rather than competitive SOTA. If the internal baseline criteria are not met, the experiment does not support the current CVPR submission framing and the method or training stability must be revisited before submission.
