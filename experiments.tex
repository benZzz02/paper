\section{Experiments}
\label{sec:experiments}

\subsection{Experimental Setup}
\label{sec:exp_data}

We adopt SurgLaVi / SurgLaVi-Beta as the pretraining resource and preserve its weakly supervised training protocol. Each sample consists of a video interval with hierarchical textual annotations. In our implementation, every sample uses its own paired caption for frame selection and contrastive alignment, while hierarchy is additionally exploited through structured mixed-level batches and hierarchical set alignment over all batch-visible parent-child relations.

Our downstream target is zero-shot surgical workflow recognition. To avoid drawing conclusions from a single coarse task, we evaluate on the broader SurgLaVi-style suite covering phase, step, action, tool, and triplet recognition. This evaluation setting is important for our method because train-time temporal denoising is expected to matter most when downstream recognition depends on fine-grained local semantics rather than only broad workflow context.

The baseline is a CLIP-style dual-encoder pretraining framework. From each annotated interval, we sample multiple frames, encode them with a domain-pretrained frame encoder, aggregate them with a lightweight temporal head, and align the resulting clip embedding with the paired caption through bidirectional contrastive learning. Our method keeps the same backbone and optimization recipe, but replaces uniform interval-level trust with train-time window denoising and adds a hierarchical set alignment loss over the fine-caption sets nested inside mid/coarse parents. Unless otherwise stated, the default configuration uses eight frames per training clip, a window expansion ratio of 1.5, a local alignment temperature of 0.15, level-aware selection temperatures of 0.35/0.8/1.6 for fine/mid/coarse supervision, an auxiliary selection loss weight of 0.7, and a hierarchical set alignment weight of 0.1.

The primary validation setting is a matched-backbone comparison under our own implementation. The baseline and the proposed model use the same pretraining data, visual encoder, text encoder, projection heads, and training schedule; the proposed model differs only in how weak supervision is consumed during training through window denoising and hierarchical set alignment. We additionally report a broader literature-positioning table for context, but the strongest method claim comes from the matched-backbone comparison.

\subsection{Ablation Study}
\label{sec:exp_ablation}

The ablation study should follow the same downstream evaluation suite while replacing cross-paper baselines with progressively stronger internal variants. The most important ablation question is not whether the full model is better than a generic literature baseline, but which parts of the train-time temporal denoising and hierarchical set alignment pipeline are actually responsible for the gains.

We therefore recommend the following progression:
\begin{enumerate}[leftmargin=*]
    \item matched CLIP-style baseline with uniform clip-text alignment;
    \item baseline + expanded training window;
    \item baseline + text-guided soft frame selection;
    \item baseline + denoised auxiliary contrastive branch;
    \item baseline + level-aware evidence granularity;
    \item baseline + structured mixed-level batches;
    \item baseline + text-side set alignment;
    \item full model.
\end{enumerate}

\subsection{Diagnostic Analysis}
\label{sec:exp_qualitative}

Because the paper is motivated by temporal imprecision in weak intervals and by underused cross-level relations, diagnostics should directly test whether the proposed model is selecting more credible frame evidence and whether hierarchical set alignment behaves as intended. We therefore recommend four types of analysis.

\paragraph{Qualitative frame-weight maps.}
Visualize sampled frames within the expanded temporal neighborhood together with their soft selection weights. Representative examples should include both successful denoising cases and failure cases where distracting context remains dominant.

\paragraph{Frame concentration statistics.}
Report summaries such as frame-weight entropy, peak frame weight, and the relative concentration patterns of fine-, mid-, and coarse-level supervision. These quantities are model diagnostics, not standalone claims about the dataset.

\paragraph{Cross-level set consistency.}
For batch-visible parent-child relations, report how much the cosine similarity between a parent selected feature and its aggregated child fine prototype increases after training, relative to the baseline. Qualitative case studies can further show whether the selected mid/coarse views preserve the weighted child semantics emphasized by hierarchical set alignment.

\paragraph{Noise robustness.}
Perturb the weak timestamps in a controlled way and compare how rapidly the matched baseline and the proposed model degrade. Such analysis directly tests whether train-time window denoising is more robust to weak temporal supervision noise than uniform clip-level alignment.
