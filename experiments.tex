\section{Experiments}
\label{sec:experiments}

\subsection{Experimental Setup}
\label{sec:exp_data}

We evaluate SurgAlign with one central question: does treating a weak interval as a noisy temporal anchor improve zero-shot surgical understanding, and if so, on which tasks? Unless otherwise stated, SurgAlign uses the same backbone family, frame budget, optimizer, and contrastive objective as the matched baseline, and differs only in how weak temporal supervision is consumed. In the primary setting, we use a LemonFM-initialized visual encoder, a SurgicBERTa text encoder, 8 sampled frames, 2 GPUs with per-GPU batch size 128, AdamW with learning rate $10^{-4}$ and weight decay $0.02$, xpool-style frame selection, interval expansion ratio $1.5$, selection-loss weight $0.7$, hierarchical-consistency weight $0.1$, and mixed-level batches with a fine/mid/coarse ratio of $80/32/16$. During training, we sample from an expanded temporal window, compute text-guided frame weights, and optimize both the global and selected branches. Test-time evaluation uses standard CLIP-style video/text encoding.

Our downstream evaluation follows the standard zero-shot surgical recognition setup and covers phase, step, action, tool, and triplet prediction. This task diversity is important for our hypothesis: if temporal denoising improves the use of local evidence, the gains should be clearest on tasks that depend on fine-grained temporal cues rather than only broad workflow context.

We organize the experiments around three questions. First, does SurgAlign improve zero-shot performance in the matched surgical-domain setting? Second, does the model actually use evidence outside the original weak interval once temporal expansion is introduced? Third, which components are responsible for the gain? To keep the intended evaluation protocol explicit, we retain the full comparison matrix and mark unfinished entries as \texttt{TBD} rather than removing the corresponding rows.

Relative to SurgCLIP-$\beta$, SurgAlign improves several zero-shot benchmarks, including Cholec80 Phase ($+4.75$ Acc / $+4.04$ F1), HeiChole Phase ($+3.47$ Acc / $+3.42$ F1), GraSP Phase ($+1.19$ Acc / $+4.31$ F1), GraSP Step ($+5.43$ Acc / $+5.27$ F1), SARRARP50 Action ($+1.22$ Acc / $+0.05$ F1), and GraSP Tool ($+1.16$ mAP). The most convincing gain appears on GraSP Step, which is precisely the kind of evidence-sensitive task for which the proposed local denoising mechanism is intended. More broadly, the gains concentrate on settings where local temporal evidence is likely to matter more than coarse workflow context.

At the same time, SurgAlign does not consistently surpass the stronger full SurgCLIP baseline. Broad phase recognition remains mixed, with notable underperformance on datasets such as AutoLaparo, StrasBypass70, and BernBypass70. We therefore view the main table conservatively: misalignment-aware training targets a real bottleneck in weak surgical VLP, but the gain is not yet stable across tasks.

\subsection{Expanded-Window Evidence Analysis}
\label{sec:exp_evidence}

The next analysis asks whether the expanded temporal neighborhood is actually used, rather than serving as a purely formal augmentation. After training, we partition sampled frames into those inside the original weak interval and those in the expanded-only region, then aggregate four statistics: outside-frame fraction, outside mass, outside-evidence enrichment relative to the uniform frame fraction, and the rate at which the top-weighted frame falls outside the original interval.

This is a mechanism check, not a new supervision signal. Under weak temporal annotation, an outside frame cannot automatically be treated as ground-truth evidence. The relevant question is narrower: does SurgAlign place non-trivial and enriched evidence mass beyond the noisy annotated boundary? If so, that would support the claim that temporal expansion and text-guided selection are functionally used by the model.

The goal here is to isolate which parts of SurgAlign matter. We therefore add the method components progressively: expanded temporal evidence, text-guided local weighting, the selected-view auxiliary loss, and hierarchical consistency.

This table is especially important for the paper narrative. If the method works for the intended reason, simple temporal expansion alone should be insufficient; the main gains should appear once the model is allowed to select text-relevant evidence and receive explicit supervision on the selected branch.
