\title{SurgAlign: Learning from Temporally Misaligned\\Weak Surgical Video-Text Pairs}
\author{}
\date{}

\begin{document}

\maketitle

\begin{abstract}
Weak video-text pairs from narrations or coarse temporal notes are attractive for scalable video-language pretraining, but they are also temporally imprecise. In surgical video, this problem is especially acute: a paired description can be semantically correct for an interval while the frames that visually justify it occupy only a short subsegment embedded in repetitive procedural context. Standard CLIP-style training ignores this structure and treats frames sampled from the weak interval as uniformly positive for the paired text. We present \textbf{SurgAlign}, a training-time framework that treats each weak interval as a noisy temporal anchor, expands it locally, and uses the paired text to softly reweight candidate frames while preserving a standard global branch and unchanged test-time inference. In matched zero-shot surgical evaluation, SurgAlign improves a matched baseline on several evidence-sensitive benchmarks, with the clearest gain on GraSP Step ($+5.43$ Acc / $+5.27$ F1), suggesting that better positive-pair construction matters when weak video-text alignment is locally noisy.
\end{abstract}
