\begin{abstract}
Weak surgical video-text pairs are often only approximately aligned in time: the text can be correct for an interval while the frames that visually support it occupy only a short subsegment or lie slightly outside the annotated center. Standard CLIP-style surgical video-language pretraining (VLP) ignores this mismatch and pools the sampled interval as a uniformly positive clip, which blurs the local evidence needed for fine-grained transfer. We present \textbf{SurgAlign}, a training-time refinement framework that treats each weak interval as a noisy temporal anchor, expands it into a bounded temporal neighborhood, and uses the paired text to compute soft frame weights for a selected local visual view. SurgAlign couples this selected view with a standard global branch, uses hierarchical caption levels only as priors on selection sharpness, and leaves test-time inference unchanged. In matched surgical-domain evaluation, SurgAlign improves multiple zero-shot surgical benchmarks, with the clearest gains on tasks that depend on localized visual evidence.

\end{abstract}
